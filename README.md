# Dlrow-Playbook
Official Dlrow Playbook for AME Wizard — Windows optimization for low latency, high FPS and maximum performance.

# ⚡ Dlrow Windows Playbook (v0.4.0)

Playbook oficial desenvolvido pela comunidade **Dlrow** para o **AME Wizard**.  
Projetado para reduzir a latência do sistema operacional, aumentar a taxa de quadros (FPS) e eliminar processos desnecessários em segundo plano sem quebrar a estabilidade do Windows.

---

## 🚀 Destaques
- **Latência Minimizada**: Temporizadores otimizados, ticks de alta precisão e escalonamento para jogos.
- **Debloat Seguro**: Remoção de telemetrias agressivas e bloatwares dispensáveis.
- **Compatibilidade**: Windows 10 (22H2) e Windows 11 (23H2 / 24H2).
- **Fácil Instalação**: Aplicação automatizada via AME Wizard.

---

## 📥 Como Instalar
1. Baixe o **[AME Wizard oficial](https://ameliorated.io/)**.
2. Baixe o arquivo `Dlrow_Optimizer_v0.4.0.apbx` na aba de **Releases** deste repositório.
3. Abra o AME Wizard como Administrador e arraste o playbook para dentro da janela.
4. Siga as instruções na tela e reinicie o computador ao concluir.
